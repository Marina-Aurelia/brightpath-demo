BrightPath 团队演示包
=====================

快速启动
--------
1. 将整个 ZIP 解压到普通文件夹，不要直接在压缩包里运行。
2. 双击 start-demo.bat。
3. 等待约 2 秒，浏览器会自动打开 http://127.0.0.1:8080。
4. 关闭名为 BrightPath Server 的黑色窗口即可停止服务。

语言切换
--------
- 默认界面为英文。
- 点击右上角“中文”可切换为中文。
- 中文界面点击右上角“EN”可切回英文。
- AI 助教回复下方的“中文解释 / English”可展开单条翻译。

包含内容
--------
- Student Dashboard
- Interactive Lesson
- Progress
- AI Tutor
- 中英双语切换

当前限制
--------
- 这是本地产品原型，不是正式上线版本。
- AI Tutor 当前使用 Rust 内置的规则回复，尚未连接真实大模型。
- 数据均为演示数据，不会上传到外部服务器。
- Windows 可能提示该内部测试程序没有数字签名。正式对外分发前应配置代码签名。

常见问题
--------
- 浏览器没有自动打开：手动访问 http://127.0.0.1:8080。
- 页面打不开：确认 BrightPath Server 窗口仍在运行。
- 提示端口被占用：关闭之前运行的 BrightPath-demo.exe，再重新启动。
